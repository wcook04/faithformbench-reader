# Security

`download` fetches four data files from the Hugging Face dataset `ighina/Faithform-AF` at a pinned revision and compares each file with a recorded SHA-256. The other commands read those files and the committed results.

`lean-sample` gives Lean statements from the release to Lean on your machine. Those statements were written by language models, and Lean can run programs while it elaborates a file, so run that command only where you accept this. No other command runs Lean.

The website is static. It reads the files that `site` writes and sends nothing anywhere.

To report a problem privately, use GitHub's private vulnerability reporting on this repository.
